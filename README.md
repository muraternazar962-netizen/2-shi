# My Branching Repo

Лабораторно-практическая работа по веткам Git.

В репозитории выполнены:
- создание веток feature-a и feature-b;
- независимые коммиты с файлами feature-a.txt и feature-b.txt;
- слияние feature-b в main;
- конфликтующие правки feature-a.txt в feature-a и main;
- ручное разрешение конфликта с сохранением обеих строк;
- проверка истории и состояния репозитория.

В этой версии используется ветка main (как на скриншоте Visual Studio Code) вместо master.
